PRODUCT ANALYTICS PLATFORM — API TEST SHEET (Thunder Client)
================================================================
Base URL   : http://localhost:8000/api/v1
Auth       : Bearer JWT (Authorization: Bearer <access_token>) for all
             dashboard endpoints. Exceptions:
               - POST /track          -> uses X-API-Key header OR ?api_key= query param
               - WS  /ws/projects/{id}/live -> uses ?token= query param (JWT)
Response envelope (every JSON response, except CSV export):
             { "success": bool, "message": string, "data": object|array|null, "errors": any|null }

Fill "TESTED RESULT" after running each request in Thunder Client.
================================================================
